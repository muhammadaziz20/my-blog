Men haqimda

Men Muhammadaziz Anvarov, dasturchiman. Frontend va backend bilan birdek shugʻullanaman: React va JavaScript bilan interfeys, PHP va Python bilan server tomoni, React Native bilan mobil ilovalar yarataman.

Hozir asosiy loyiham — maktab uchun PHP asosidagi boshqaruv tizimi. U oʻquvchilar, baholar va toʻlovlarni bir joyda yuritadi, interfeysi esa toʻliq oʻzbek tilida. Unga Telegram bot ham qoʻshganman: ota-onalar va oʻquvchilar baho va toʻlovlarni bot orqali koʻra oladi.

Jamoada ham, yolgʻiz ham ishlay olaman. Ingliz tilini Multilevel B2 darajasida bilaman va hozir taxminan 3 oydan keyin topshirmoqchi boʻlgan IELTS imtihoniga tayyorlanyapman.

Vazifalarni boʻlishish, kodni birga koʻrib chiqish va fikrni ochiq aytishni yaxshi koʻraman. Jamoa ichida tez oʻrganaman va boshqalarga ham yordam beraman.

Qanday loyihalarda ishlay olaman?

Veb-saytlar, boshqaruv tizimlari, Telegram botlar va React Native yordamida mobil ilovalar. Frontend va backend qismlarini ham alohida, ham birga qila olaman.

Jamoaga qoʻshila olasizmi?

Ha. Jamoa bilan ishlashni yaxshi koʻraman va shu bilan birga 1 yillik yolgʻiz ishlash tajribam ham bor.

Qaysi tillarda muloqot qila olasiz?

Oʻzbek tilida va ingliz tilida (Multilevel B2). Hozir IELTS ga tayyorlanyapman.

Siz bilan qanday bogʻlansam boʻladi?

Quyidagi "Aloqa" boʻlimidagi havolalar orqali yozing.

Birga ishlaymizmi?

Jamoa loyihasi, frontend yoki backend vazifasi boʻlsa, yozing.
